# Red-Green Stacked PR の実例

Zenn記事「[不具合をCIに刻む「Red-Green Stacked PR」のすすめ](https://zenn.dev/bmth/articles/red-green-stacked-pr)」で紹介している運用を、実際のPRとして残したリポジトリです。

`src/tax.ts` は税抜価格から税込価格を求めます。
仕様は1円未満の切り捨てですが、実装は四捨五入しています。
小数部が0.5以上になる金額でだけ、正しい額より1円多く返す不具合です。

## PRの構成

| | 内容 | CI |
| --- | --- | --- |
| PR 1 | `test.fails` で再現テストのみを追加 | ✅ 現在の実装でテストが落ちることを検証 |
| PR 2 | `.fails` を外し、実装を修正 | ✅ 同じテストが通ることを検証 |

PR 2 は PR 1 をベースブランチに指定してスタックしています。
2つのCI結果を並べることで、Red→Greenの遷移がCIの履歴だけで確認できます。
